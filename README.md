# Forum Sistemi — Katılımcı Yönetişim Forumu

Herkesin konu açabildiği, düzenleme teklif edebildiği ve kararların **"Köprülü Çoğunluk"** algoritmasıyla alındığı bir katılımcı
yönetişim platformu. Aynı React kodu hem **web sitesi** hem **Android uygulaması** (Capacitor) olarak çalışır. Sistemde şunlar bulunur:

- yönetmeliği denetleyen bir **ontoloji** (RDF/OWL + N3 kuralları + SHACL),
- 4 doğrulayıcılı **dağıtık defter** (BFT),
- **bilirkişi** kurası,
- **yapay zekâ** danışmanı (Claude; anahtar yoksa çevrimdışı sezgisel mod),
- insan ilişkilerini tutan bir **graf**.
